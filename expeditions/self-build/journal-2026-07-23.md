# Journal: self-build — 2026-07-23

The journal is inked while the fire still burns, before memory softens the day into a better story. Entries are maps, not mandates: they inform future judgment, never bind it.

## The day's discoveries

- Both harnesses now carry a plugin mechanism, and the two formats are near mirrors: `.claude-plugin/plugin.json` and `.codex-plugin/plugin.json`, skills under `skills/<name>/SKILL.md`, a plugin-root variable (`CLAUDE_PLUGIN_ROOT`, `PLUGIN_ROOT`), and marketplace catalogs installable from a git repository. One repository can be the plugin root for both at once.
- With the repo as the plugin, the vendoring problem dissolves rather than being managed: skills reference `creed/`, `templates/`, and `spec/` at the plugin root, and nothing is copied. The `adapters/claude` and `adapters/codex` trees were retired.
- A skill can describe its resource location for three install modes in one paragraph (plugin root two directories up, or inside the skill folder for a standalone build), letting one SKILL.md serve every channel.

## Failed crossings

## Corrections to the map

- Earlier entries treat the self-contained skill folder as the unit of distribution. That holds now only for the standalone `.skill` channel, built on demand into `dist/`; the plugin, with shared resources at its root, is the primary packaging.
