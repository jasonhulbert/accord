# Dispatch: self-build — 2026-07-21

## Miles gained

All six basecamps reached in one march. The repo carries the layered structure with the canon byte-for-byte unchanged; templates for charter, dispatch, and journal entry; the journey-state spec, schema, example log, and validator; the self-contained Claude skill and its build script producing `expedition.skill`; the map rendering and analysis notes; and this expedition's own log, validated and rendered.

## Crossings lost

None outright. One stumble: the browser preview could not open the rendered map from a file path, so verification went over a local server instead — a detour, not a failed ford.

## Landmarks found

- The canon already names nearly every field the templates need; the templates mostly transcribe.
- A generic JSON Schema validator would have brought a dependency; interpreting the small subset the spec uses kept `tools/validate` stdlib-only with the schema file still the source of truth.
- Writing this log retroactively for B1 was easy; keeping it live from B2 onward was easier. The substrate costs little in motion.

## The trail ahead

The expedition is home. What remains belongs to the patron: the scout-clarification wording for the canon, and any publishing decisions — both riders in the charter, neither acted on.
